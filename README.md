# ArtaniPaylas

ArtaniPaylas, gıda ve giysi/eşya yardımlarının ihtiyaç sahiplerine güvenli ve hızlı şekilde ulaşmasını hedefleyen, Ayancık Belediyesi ortaklığı ile yürütülen bir sosyal dayanışma platformudur.

## Kısa Bilgi

- **Teknoloji Stack'i:** `.NET 8`, `ASP.NET Core MVC`, `EF Core`, `PostgreSQL`, `Tailwind CSS`, `Leaflet.js`
- **Proje Katmanları:**
  - `ArtaniPaylas.Core`: Entity'ler, ViewModel'ler, Enum'lar ve Arayüzler.
  - `ArtaniPaylas.Data`: DbContext, Veritabanı Migrations ve Somut Servisler.
  - `ArtaniPaylas.Web`: Controllers, Views, Middleware ve Web Sunucu Yapılandırması.
